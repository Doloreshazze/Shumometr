# Декларация foreground service

Тип: `microphone`.

Основной пользовательский сценарий — длительное измерение окружающего шума и
ведение журнала при погашенном экране. Пользователь запускает измерение явной
кнопкой. Android показывает постоянное уведомление с текущим уровнем и действием
«Остановить». Измерение также останавливается из главного экрана приложения.

Фоновая работа необходима: без foreground service Android приостанавливает доступ
к микрофону, и круглосуточный журнал получает разрывы. Расшифровка необязательна,
включается отдельно после заметного уведомления и выполняется локально.

Для видео модератору показать: запуск → запрос микрофона → постоянное уведомление
→ погашение/возврат экрана → продолжающийся график → остановка из уведомления.
