# Data safety — рабочие ответы

Проверить ещё раз непосредственно перед публикацией при изменении функций.

- Данные собираются разработчиком: **нет**.
- Данные передаются третьим лицам: **нет**.
- Аудио покидает устройство: **нет**.
- Распознанный текст покидает устройство: **нет**.
- Данные шифруются при передаче: неприменимо, пользовательские данные не передаются.
- Удаление данных: очистка данных Android или удаление приложения.
- Необязательный CSV создаётся только по команде пользователя в выбранном им месте.
- Скачивание файла модели не содержит аудио или текста пользователя.

Разрешения и цели:

| Разрешение | Цель |
|---|---|
| RECORD_AUDIO | измерение, спектр и выбранная пользователем офлайн-расшифровка |
| FOREGROUND_SERVICE_MICROPHONE | измерение при погашенном экране |
| POST_NOTIFICATIONS | постоянное уведомление измерения |
| SYSTEM_ALERT_WINDOW | необязательный плавающий виджет |
| INTERNET / ACCESS_NETWORK_STATE | загрузка офлайн-модели по команде пользователя |
| WAKE_LOCK | поддержание активного измерения |
