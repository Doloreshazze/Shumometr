# Участие в разработке

Для сборки нужны JDK 17 и Android SDK 35. Перед pull request выполните:

```bash
./gradlew test lintRelease assembleRelease bundleRelease
```

Не добавляйте в репозиторий модели, APK/AAB, журналы пользователей и ключи подписи.
Изменения обработки аудио должны сохранять главный принцип: микрофонный поток не
блокируется распознаванием и не передаётся по сети.
