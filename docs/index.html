Политика конфиденциальности приложения «Шумометр»

Последнее обновление: 2 сентября 2026 года.

Кратко

Приложение не передаёт разработчику аудио, распознанный текст, измерения или идентификаторы устройства. Анализ шума и распознавание выполняются локально.

Микрофон

Микрофон используется для измерения уровня, построения временного графика и частотного спектра. При включённой расшифровке короткие фрагменты обрабатываются офлайн-моделью. Непрерывный исходный звук не записывается в файл.

Локальные данные

Статистика измерений, настройки и распознанный текст сохраняются в приватном хранилище приложения на устройстве. Пользователь выбирает срок хранения и может самостоятельно экспортировать CSV. Удаление данных доступно через очистку данных или удаление приложения.

Сеть и модель

Интернет используется только по явной команде пользователя для загрузки офлайн-модели распознавания. После загрузки распознавание не требует облачного сервиса.

Плавающий виджет

Необязательное разрешение «поверх других приложений» используется только для показа выбранного пользователем мини-графика. Оно не применяется для чтения содержимого других приложений.

Дети и третьи лица

Приложение не предназначено специально для детей. Пользователь отвечает за законность распознавания речи и информирование находящихся рядом людей.
