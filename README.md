# Шумометр (NoiseLog)

[Политика конфиденциальности](https://doloreshazze.github.io/Shumometr/) ·
[История изменений](CHANGELOG.md) · [Сторонние компоненты](THIRD_PARTY_NOTICES.md)

Идентификатор устанавливаемого приложения: `com.playeverywhere.graphmetr`.
Он отличается от обеих ранних сборок — `com.playeverywhere.noiselog` и
`com.playeverywhere.shumograf`, поэтому Android считает эту версию отдельным
приложением. В меню она называется «Шумометр», чтобы её было легко
отличить от старой копии.

Android-шумомер с круглосуточным журналом, временной формой сигнала, частотным спектром и локальной расшифровкой речи без словесного фильтра.

Версия 1.3.1 добавляет выбор конкретного языка распознавания. Режим «Авто»
по-прежнему использует Omnilingual ASR для 1600+ языков, а выбранный язык
передаётся компактной многоязычной Whisper-модели как реальная языковая
подсказка.

Версия 1.3.0 добавляет релизные материалы, adaptive icon, CI-проверку,
политику конфиденциальности и заметное согласие перед непрерывной локальной
расшифровкой.

Версия 1.2.2 исправляет рассинхронизацию, при которой служба уже остановилась,
а экран продолжал показывать `0 дБ` и кнопку «Остановить измерение». Также
тяжёлые запросы журнала и проверка языковой модели вынесены из главного потока,
сокращены лишние копирования данных и повторные перерисовки.

Версия 1.2.3 изолирует тяжёлую модель распознавания в отдельном процессе:
если ONNX долго обрабатывает фразу, измеритель, графики и кнопка остановки
продолжают работать. Голосовой сегментатор теперь использует компактные PCM-
массивы без сотен тысяч объектов и режет длинную речь на фразы до 5 секунд.

Версия 1.2.4 завершает процесс распознавания штатно. Это устраняет ложное
аварийное закрытие, которое оболочка Samsung показывала после принудительной
остановки вспомогательного процесса модели.

## Возможности

- оценка уровня в дБ(A) и линейного уровня с частотой дискретизации 48 кГц;
- живая осциллограмма и логарифмический спектр 20 Гц–20 кГц;
- доминирующая частота и график уровня за последние три минуты;
- foreground service с постоянным уведомлением и поддержкой погашенного экрана;
- перетаскиваемый оверлей-виджет с осциллограммой, частотным спектром, уровнем дБ(A) и пиковой частотой;
- экономичная отрисовка оверлея: данные прореживаются и обновляются только четыре раза в секунду;
- минутная статистика: минимум, максимум, среднее и Leq;
- журнал за 24 часа, 7 и 30 дней, хранение до выбранного срока;
- экспорт минутной статистики и текста в CSV;
- автоматическое офлайн-распознавание на 1600+ языках моделью Omnilingual ASR;
- выбор одного из 99 языков с фиксацией языка в компактной Whisper-модели;
- сохранение результата распознавания без цензуры и замены слов;
- исходный звук не записывается и не отправляется на сервер.

## Установка

Готовый `arm64-v8a` release APK подходит для Samsung A72 и большинства современных телефонов. Он собран из исходников и подписан штатными схемами Android v2/v3. Его можно установить обычным открытием файла. Если Android предупреждает о неизвестном источнике, разрешите установку для приложения, из которого открываете APK. При сборке также создаётся universal APK для 32- и 64-битных ARM-устройств.

Новая ветка имеет собственное хранилище. Журнал, настройки и загруженная модель
из прежней версии автоматически не переносятся. Старую копию можно удалить
после проверки новой.

Готовый APK подписан отдельным постоянным ключом этой ветки, поэтому следующие
обновления с тем же ключом будут устанавливаться поверх неё. Закрытый ключ в
архив исходников намеренно не включён.

Для расшифровки на вкладке «Сейчас» выберите язык и нажмите «Загрузить модель».
Автоматический режим загружает универсальную модель размером около 365 МБ;
режим конкретного языка — компактную модель около 105 МБ. Файлы хранятся в
приватной папке приложения. Сам шумомер, спектр и журнал работают без них.

Чтобы включить плавающий индикатор, откройте «Настройки» → «Плавающий виджет» и один раз разрешите показ поверх других приложений. Крестик скрывает только виджет — измерение и журнал продолжаются.

## Важные ограничения

Телефонный микрофон не является поверенным измерительным прибором. До калибровки показания абсолютного уровня приблизительны, хотя изменения уровня и спектра остаются полезными. Для калибровки положите рядом эталонный шумомер и задайте поправку в настройках.

Android требует постоянно видимое уведомление при круглосуточном использовании микрофона. После перезагрузки телефона измерение нужно запустить вручную. На некоторых телефонах Samsung полезно исключить приложение из оптимизации батареи.

Автоматическая модель поддерживает более 1600 языков, а режим фиксированного
языка — 99 языков Whisper. Ни один распознаватель не гарантирует каждое слово:
ошибки возможны при шуме, далёком микрофоне, одновременной речи и редких
диалектах. Программного списка запрещённых слов в приложении нет.

## Сборка проекта

Требуются JDK 17 и Android SDK 35.

```bash
./gradlew test lintRelease assembleRelease bundleRelease
```

APK для современных ARM64-телефонов появится в
`app/build/outputs/apk/release/app-arm64-v8a-release-unsigned.apk`; рядом будут 32-битная
ARM-версия и universal APK.

Неподписанный App Bundle для Google Play появится в
`app/build/outputs/bundle/release/app-release.aab`. Релизный ключ не хранится в
репозитории: AAB следует подписывать upload-ключом вне CI либо через защищённые
секреты выбранной системы сборки.

## Использованные компоненты

- [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) — локальный ASR runtime;
- [Omnilingual ASR](https://github.com/facebookresearch/omnilingual-asr) 300M int8 — загружаемая модель для 1600+ языков;
- [Whisper](https://github.com/openai/whisper) tiny int8 — загружаемая модель для фиксации выбранного языка;
- Android AudioRecord, SQLite и DownloadManager.

Код приложения распространяется по лицензии MIT. У загружаемой модели и зависимостей есть собственные лицензии, указанные в их репозиториях.
